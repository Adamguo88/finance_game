# v0.2 多軌事件時間軸

本輪延續已合併財務切片，將既有事件投影為住宅、職涯、租金、薪資四軌；既有負債排程為初始條件，本輪不作事件拖曳。V1 僅顯示住宅/職涯，V2 顯示四軌。不增加財務事件或更改公式/schema/engineVersion。

- 位置以整數月份表示，範圍 1 至人生 horizon。刻度包含月 0；失業區段標出實際有效月份，截於 horizon，拖曳只改開始月，保留 duration 與所有參數。
- 編輯模式可用滑鼠/觸控拖曳，放開才提交一次。方向左右鍵一次一月，Shift + 方向鍵一次一年。Enter/點擊開啟既有編輯視窗，視窗仍可輸入確切月份。
- 體驗與比較模式只定位月份，不改參數；比較模式顯示目前選取操作的方案，標明名稱，與比較的共用月份同步。
- 分支點以前（含該月）的事件不可移動，未來事件不可移入鎖定區。原始資料先套用才能重排。非法重疊、同類同月、超出期間等皆沿用 domain 驗證，拒絕時目前方案、history、revision 與月份不變。
- 拖曳預覽不計算/保存；放開後只改事件 month，走 changeEvents，保留原版本歷史並重新計算。未移動及取消手勢不產生歷史。父子互相隔離。範圍外拖曳會吸附到合法邊界，鍵盤超界不改動。
- 長時間軸在區塊內水平捲動，避免整頁溢出；相鄰卡片分行避免互相遮擋。提供「定位目前月」，保留原有月份滑桿與事件清單作替代操作。
