## 納入與不自動推導的邊界

「自訂事件」採可命名、可設定日期與參數的已知型別模板；不執行使用者任意JS、自由公式或自由文字效果。結婚、生養、醫療、退休均由事件明確設定，不由年齡／外觀推論。稅費、持有成本、保費、保障、收益／虧損等必須提供參數；填0代表使用者明示零成本／零報酬假設，缺少必要資料不能假裝真實成本為0。

真正3D、同步／共享與AI依既有路線待長期另訂；隨機事件與後端不納入。自動稅制／核保、法律理賠判定、每日計息、交易撮合、違約／征信模型沒有足夠條件，不自動模擬；已知成本可用明確金額／期間輸入。這些界線不排除本PC契約中的保險、投資、退休或清償功能。

## 全域時間、資料與金額規則

- 月0是起點，事件月1至當前人生終點；沿用18–89歲起始、最晚90歲與864月上限。事件／實體的有效區間為[start,end)，end=null表示到模型終點。超出終點不產生現金流；期間無效拒絕。
- 金額為整數分；參數與計算均須有限、可驗證，溢出safe integer拒絕整個候選。金額／數量的輸入上限與版本線路由#42落定，不偷放寬舊格式。每一個正數金額分量以half-up取到分，再合計；投資／價格先將非負資產重估值取分，再計差額，不對負報酬差額另作不同取整。
- 原始參數是主資料，快照可重算。現金、資產、負債、收入、消費、利息、費用、借還本金及資產轉換分開，淨資產=現金+資產−負債。借款不是收入，還本金不是生活費，買資產不是把全價再列一次消費。
- 初始多筆明細須映射穩定財務ID，不能把所有收入當同一份薪資。租金對應指定expense，還款對應指定liability，現金只記一次；#29的名稱／金額輸入不是完整可執行實體，#42另定生命週期及映射。
- 修改／取消預覽不寫入工作或DB；套用保存前一版及revision。分支點為月末，<=forkMonth鎖定，父方案後改不傳播。事件可指向分支自己的穩定ID，不能讀父方案目前狀態。

## 同月順序與衝突

新版明確保存可見的同月sequence；舊事件轉換時保留原有有效順序，不用隨機UUID決定有爭議的新分配。相同階段先遵守依賴，再按sequence、最後ID排序；依賴循環、重複sequence或同月對同一屬性兩次無法合併的設定拒絕，不能靠排序悄悄覆蓋。

| 階段 | 月度處理 |
|---|---|
| 0 | 啟閉成員／收入／支出／退休／保障；參數變更。明確設定的當月金額優先於該月通膨，之後各月才繼續指數化；失業只是指定來源的期間覆蓋，不覆蓋正常薪資基準 |
| 1 | 對月初已有且已到第一付款月的排程算當月利息。指定可變利率的變更先生效，固定利率契約不可被環境事件悄改 |
| 2 | 處理一次收入／借款、資產出售與連帶結清、獨立清償／再融資、購買／投資轉入轉出、一次支出／損失／理賠。結構依賴優先，ready事件依上述類別與sequence排序；同月損失必須先確認保障與保留額度，才能收取其理賠 |
| 3 | 依有效期間結算各收入、支出及保費；失業覆蓋只影響指定來源，其他來源保留 |
| 4 | 新借款若當月即第一付款月，計一次完整月利息；合併月初已算的應付利息，對未結清排程扣常規本息，再執行明確的部分提前還本。售出／全清／再融資已清償的舊貸不得再扣常規款 |
| 5 | 記錄月末分項／彙總快照、缺口與事件來源，供場景／時間軸／故事書／報表共同消費 |

月度模型不保證同月每日流動性或按天利息。允許現金為負以顯示缺口，所有預定收支／本息仍按契約記錄，不自動借款或推論違約。新購資產不允許同月再出售／重估，新借款不允許同月再清償／再融資；相關操作須改期，避免以零持有期鑽取月份規則。部分提前還本與全清／再融資／出售結清同貸同月互斥。不同實體的獨立事件可以同月並存。
