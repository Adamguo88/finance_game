# 開發路徑與優先順序

更新：2026-11-26（Asia/Taipei）。本頁維護整體路線；當前順序與驗收見 [NEXT_PHASE.md](NEXT_PHASE.md)，功能矩陣見 [PC_SCOPE.md](PC_SCOPE.md)。GitHub issues 是任務狀態來源，合併 PR 與 [VALIDATION.md](VALIDATION.md) 是交付證據。

## PC 優先

先完成 PC 全部規劃功能、UI／UX 與角色／場景建模並驗收，再啟動 iPad／手機 #25。現階段以桌面滑鼠／鍵盤及 PC 效能為主；既有響應式能力與手機回歸保留。3D、AI、後端、登入與隨機財務事件不在目前範圍。

## 路線與狀態

| 階段 | 現況 | 完成閘門 |

## 交付規則

每項先訂契約與可測驗收，再以獨立 PR 實作。新財務公式必須有新引擎版本、數值與遷移測試，不能默默改算。CI 觸發與 Pages 分別依 [CI.md](CI.md) 核對；自動測試、代理檢視、真人驗收及正式發布分開記錄。

過時的初始任務與建單資料已移除，歷史保留於 Git／PR；不得重新建立已完成 issues。本輪僅整理文件與排程，沒有啟動背景開發或實作新功能。
