# PC 旅程與工作室 UI／UX

Issue #16，依 PC_SCOPE 與原討論 P01–P08 實作。主要桌面尺寸為 1280×800、1440×900；沿用現有財務引擎及四類事件。

## 主要流程

- 首頁：開始我的人生旅程、讀取人生存檔、探索範例人生、匯入 JSON。從工作室回首頁可返回目前記憶體中的工作，不把它稱為本機存檔。
- 新建五步：人生名稱/年齡 → 正常收入 → 生活費/租金 → 現金/其他資產 → 既有負債及確認。可返回修改，右側顯示以引擎推導的起始世界、月剩餘現金流及淨資產。完成前不替換工作，確認建立也不自動覆寫 IndexedDB。
- 新人生直接使用 V2、migration=null、revision/profile.version=1、空 events/history，與舊範例 V1 的明確升級流程分開。不能把範例歷史混入使用者的新人生。
- 工作室：財務 HUD 優先、中央世界、下方共用時間與事件軌道；PC 初始資料/事件工具在獨立捲動旁欄。新建人生的長資料表預設收合，精確編輯仍可展開；範例保留展開，方便探索既有輸入。
- 體驗模式收起編輯表單/事件庫，保留時間、分支及數據；平行人生沿用共用月份/最短終點及各自年齡。無效事件、草稿、匯入/存檔失敗保護不變。

## 狀態與可還原性

三個提示互斥：表單尚未套用、工作尚未儲存、已儲存至本機。只有成功 save/load 才顯示已儲存；匯入、建分支、改參數/事件、轉換模型或新建工作都需另存。匯出 JSON 不代表 IndexedDB 已更新。

sessionStorage 只記錄目前顯示首頁/工作室，避免重新整理時強制跳首頁；它不保存財務資料。重新整理後仍須讀取本機存檔才能還原工作，不宣稱未儲存資料可跨刷新還原。輸入草稿會阻止離開工作室；新人生確認頁明示取代目前工作與先備份。

滑鼠/鍵盤均可走完新建、事件預覽、分支、比較與備份；事件視窗維持 Tab 圈限、Escape、返回焦點。操作訊息在工作室以可見的 status 顯示；忙碌時禁止衝突操作。
