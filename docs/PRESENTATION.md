# 角色動作、轉場與音效（#19）

## 共用時間與有限動畫

財務月份仍由唯一 playback store/setInterval 推進，renderer 不能更改月份、事件、快照或存檔。Studio 由同一個 commit 產生所有比較世界共用的 cue（start、duration、token），不另啟方案時鐘。

僅在同範圍、相同播放速度、連續播放往前一月時產生動畫。角色做輕微步伐/起伏，購屋與職涯事件加上對應模型淡入。一次轉場最多 220ms，4× 為 175ms、12× 約 58ms，短於下一個月度 tick。轉場使用有限 RAF，結束後回復快照的精確位置/透明度，不維持常駐 ticker。每個世界只保留一個取消函式，新 cue、暫停、切速度、回溯、跳月或卸載皆取消舊效果，不排隊、不延後財務畫面。

手動逐月/跳月與 SVG 備援直接呈現同月狀態；沒有動畫也能透過既有文字、HUD 與區域明細理解變化。GPU 仍最多 4 個。減少動態效果不影響財務時間、事件或文字。

## 偏好與背景

時間軸上方「體驗設定」提供減少動態效果、靜音、四級音量及試聽。系統 prefers-reduced-motion 為 reduce 時強制減少動態，並監聽即時變更；使用者亦可自行減少。偏好獨立保存於 localStorage，不能寫入版本化 Project/JSON；損壞或無法保存時使用可操作的預設值。

document.hidden 會停止音效並暫停共同播放；回前景由使用者按播放，避免背景計時與回來後補播。切模式/方案、事件視窗、存檔操作與首頁沿用播放停止流程，同時取消對應轉場/音效。

## 音效與授權

預設靜音。僅使用者取消靜音、按播放（曾解除靜音）或試聽的操作可建立/恢復 AudioContext；不在載入或讀取偏好時自動建立。聲音是本專案以 Web Audio 正弦波即時合成的短雙音，沒有外部檔案、音樂來源、網路或新增素材授權。

每個連續播放的事件月份最多一組短音，不會因比較方案數量疊加。以 scenario ID/revision/event ID 在工作階段去重；回溯再播放、切模式、重複 render 不重複發聲；新建/匯入工作或新版本事件可重新體驗。靜音期間經過的事件也標記已經過，不會在解除靜音後補播。跳月/逐月無音效。試聽是使用者明確要求的例外。

最多兩個短 oscillator（各 ≤225ms）；新聲音先停止/斷開舊聲音。暫停/靜音/零音量/背景會清理 voices 並 suspend context，卸載 close；不排隊。裝置不支援或無法恢復音效時顯示簡短提示，其他規劃功能繼續可用。

## 驗證界線

純 presentation policy/有限 RAF 的單元測試，與真 WebGL、Web Audio E2E 驗證中止、系統偏好、背景、比較同步、1×/4×/12× 切換、去重、JSON 不變與偏好重載。聲音測試觀察真 AudioContext/oscillator 的啟動，不將 CI 無揚聲器測試稱為真人聽感驗收。硬體 FPS、長時間記憶體、多瀏覽器與真人視覺/音量評估仍在 #24。

## 本機量測

#18 initial gzip JS 為 258,303 bytes；本輪根路徑為 260,408（+2,105），全部 chunks 為 450,057。資產仍為原 12 個 SVG（15,783 bytes），音效沒有額外檔案。最終 head 的量測另見 VALIDATION。

1440×900、系統 Chromium 156、SwiftShader 的月 1 至 3 短測，觀察到 11 個動畫 RAF timestamp；排除兩次轉場之間的空檔，8 個間隔中位 33.3ms、P95 250.1ms，3 個超過 33.4ms。這個軟體 GPU 樣本含慢幀，未達可宣稱真實硬體 60 FPS 的證據。轉場以絕對共用時間計算，超時直接落定，不補播；真人 PC 硬體與長測仍由 #24 驗收。測試不是主觀聽感或跨瀏覽器效能保證。
