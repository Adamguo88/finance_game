# PC 事件庫與影響預覽契約

延續多軌時間軸與 PC 優先規格。本輪事件庫收錄現有購屋、職涯暫停、租金調整、正常薪資調整四種事件，提供搜尋、類別篩選、參數與效果說明。這是現有事件的選擇/編輯流程，不增加財務類型、預測、隨機事件或新公式。

- 選擇模板只開啟設定視窗，不直接寫入。V1 只允許購屋/職涯，V2 才能選租金/薪資；已購屋、事件數量上限等限制明示原因。
- 設定視窗在輸入有效後顯示事件當月與 90 歲終點的原方案/預覽現金、負債、淨資產及差額。兩邊採相同月份、相同引擎與其他事件，只將目前編輯事件替換或加入一次。
- 已存在事件採 ID 替換，不雙重套用；新草稿使用不碰撞的臨時 ID，正式儲存才產生正式 ID。所有 schema、分支鎖定與衝突檢查沿用 changeEvents，不能藉預覽繞過。
- 預覽是衍生結果，不寫 project、history、revision 或 IndexedDB；取消/搜尋/篩選不改資料。只有「儲存事件」才更新工作，儲存至裝置仍需原儲存按鈕。
- 輸入缺漏或無效時不顯示舊的有效結果；切換欄位以短延遲更新預覽，不讓財務運算阻塞每個按鍵。預覽失敗顯示原因，不替使用者調整參數。
- PC 滑鼠/鍵盤可完成搜尋、選擇、編輯、取消；視窗焦點圈限、Escape 與返回原入口均可用。保留原四種快速新增入口。原生手機/iPad 適配延後。

數值例（初始 26 歲、現金 800,000 元、其他資產 200,000 元、收入 50,000 元、支出 30,000 元）：第 12 月薪資改為 60,000，當月現金由 1,040,000 變成 1,050,000，淨資產差額 10,000；第 768 月差額為 7,570,000。若將該已存在事件改為 70,000，預覽只增加新舊差額，不重複加入事件。購屋、失業與停租仍使用既有財務契約。
