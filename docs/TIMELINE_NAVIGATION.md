# PC 長期時間軸與密集事件導覽（#20）

沿用四軌、`rescheduleEvent` 的版本/歷史與衝突驗證，沒有重建財務計算或重排契約。顯示設定不進入 Project/JSON。

## 縮放與共同月份

- 月份詳覽：每月 48px，逐月刻度，適合精確拖曳。
- 年度規劃：沿用原每月 16px；每 12 月顯示一年，舊拖曳/鍵盤操作保持原比例。
- 全人生概覽：以可用寬度適配 0–horizon（最長 864 月），最小每月 .5px；窄視窗仍可在區塊內水平捲動，不擴張行動端適配範圍。刻度以 1/2/10 年顯示，終點固定可見；末端太接近前一刻度時合併，避免標籤擠在一起。

縮放保留原可視區中心月份（依邊界夾限），不改共同播放月份或事件參數。「定位目前月」置中游標；「跳至第幾月」接受 0–期間上限的整數（比較模式採最短人生的共同上限，不能輸入後靜默截短），暫停後跳至該月並定位。空白、負值、分數或超界輸入被拒絕，保留工作；Escape 還原目前月。輸入錯誤與欄位以 aria-invalid/aria-describedby 連結。

## 密集卡片與焦點

卡片至少 144px，每列保留 8px 間隔，依時間/ID 穩定分列；職涯暫停同時顯示持續期間及比例底線。100 個事件都保留原生按鈕，不用虛擬清單卸載焦點。軌道最高 520px，內部雙向捲動，軸與軌道標籤固定，scroll padding 預留標籤/刻度空間。

「尋找事件」以月份/標題列出完整排程，只捲動並聚焦，不改目前月；可跨長距離尋找最後一張。上下鍵選同軌相鄰卡片，Home/End 到首末張，Tab/Enter 沿用原生按鈕流程。編輯後保留原卡片 DOM/key 與焦點；不因選取而更動財務。

## 重排與取消

左右鍵仍移動一月，Shift＋左右鍵一年；按住的 repeat 不重複提交。鎖定事件可聚焦檢視，不能重排。鍵盤超界/衝突沿用原拒絕訊息及 history 不變性；事件編輯視窗保留精確發生月份輸入。

拖曳開始捕捉當下比例/位置及水平捲動量，超過 4px 才進入移動，避免邊緣點選抖動造成自動捲動/誤改。進入拖曳後靠邊的 pointer move 可有限向該方向捲動，不另啟 RAF。預覽依整月吸附及分支/人生邊界夾限；pointer up 只提交一次，Escape、pointer cancel、遺失 capture 或改縮放取消預覽。來源/事件參數/歷史只由既有 domain 操作更新。

## 驗證界線

74 項單元包含 100 卡片/三種縮放不重疊、輸入不變、期間與終點刻度。新 E2E 使用合法上限 20 個方案、每方案 100 事件、18–90 歲（864 月），測匯入、切方案、概覽、事件尋找與首末焦點、精確跳月、JSON 不變。這是上限資料導覽，沒有以一次同時呈現全部 20 個 GPU 世界代替 #24 的完整效能驗收；GPU 上限仍為 4。

既有拖曳、跨分支鎖定、衝突拒絕、保存重載、草稿保護與既有手機回歸測試保留。本輪以 PC 為開發目標；真人多瀏覽器、長時間記憶體與硬體延遲仍待 #24。

## 本機量測

Node 24.22.3 / Chromium 156，1440×900。合法 20 方案 ×100 事件的匯入至第一張完整時間軸約 1.6–2.0 秒，包含首頁載入、JSON 驗證、模擬與瀏覽器自動化；不是純互動延遲基準。100 張卡片在三種比例皆可保持分列，原始事件與匯出 JSON 不變。

根路徑 production initial script URLs 去重逐檔 gzip（mtime=0）合計 261,997 bytes；全部 chunks 451,646。相較 #19 已記錄約 260.4KB，新增約 1.6KB gzip；不是實際 HTTP Brotli、字型或 CSS 下載大小。沒有新模型、音檔、依賴或外部服務。真人 PC 硬體的 100ms 互動/FPS 目標不以此端到端測試代填。
