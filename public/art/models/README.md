# Life Studio editable vector assets

Original project artwork, exported from `src/scene/models.tsx` through `scripts/export-models.mjs`. No third-party images or 3D model downloads are included. Follow the repository's licensing policy; no additional third-party asset license has been introduced.

`manifest.json` records the nine model IDs, Chinese display names, file sizes and SHA-256 digests. Modify the TSX vector source and regenerate the standalone SVG pack together. Coordinate/anchor/state details and the local export command are documented in `docs/WORLD_ASSETS.md`. The static `/scene-gallery/` page is the visual review atlas.
